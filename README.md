# Machine Learning Lab Practicals

This repository contains Machine Learning practical assignments and their corresponding datasets. The practicals cover exploratory data analysis, data preprocessing, and various regression techniques using Python and Scikit-Learn.

## Repository Contents

### 1. Titanic Dataset Analysis (`PRAC1.ipynb`)
- **Dataset:** `titanic.csv`
- **Description:** Exploratory Data Analysis (EDA) and preprocessing on the classic Titanic dataset. This practical typically involves handling missing values, visualizing survival rates, and preparing categorical features for model training.

### 2. USA Housing Price Prediction (`PRAC2.ipynb`)
- **Dataset:** `USA_Housing.csv`
- **Description:** Predicting house prices based on various features such as area income, house age, number of rooms, and population.
- **Models Implemented:**
  - Simple Linear Regression
  - Multiple Linear Regression
  - Ridge Regression
  - Lasso Regression
- **Features:** Includes a custom input cell at the end of the notebook to interactively predict house prices by providing custom values.

## Prerequisites

To run these notebooks, you will need Python installed along with the following libraries:
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `scikit-learn`
- `jupyter` (to run the `.ipynb` files)

You can install the required packages using pip:
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

## How to Use

1. Clone this repository to your local machine.
2. Open a terminal or command prompt in the repository directory.
3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Open `PRAC1.ipynb` or `PRAC2.ipynb` to view the code and execute the cells step by step.
